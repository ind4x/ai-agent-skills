# Centralized Agent Skills Collection

A curated, categorized, and fully standalone repository of **106 production-grade agent skills** formatted according to the open `SKILL.md` specification.

This collection unifies skills originating from diverse agent ecosystems—including Google Antigravity, Anthropic Claude Code plugins, Microsoft / Copilot CLI plugins, the CLI Agent Orchestrator (CAO), Playwright, Hardhat, FastAPI, and community toolkits—into a standardized, searchable library ready for version control, sharing, and immediate deployment.

## How to Share and Deploy

### 1. Publishing to GitHub

To publish this centralized collection to your GitHub profile:

```bash
cd /home/youssef/skills
git init
git add .
git commit -m "feat: initial release of centralized and categorized agent skills library"
git branch -M main
git remote add origin git@github.com:ind4x/<repo-name>.git
git push -u origin main
```

### 2. Loading into Google Antigravity / Gemini CLI

Link individual skills or an entire category into your global Antigravity skills directory (`~/.gemini/skills/`):

```bash
# Link a single skill
ln -s /home/youssef/skills/design-ui/impeccable ~/.gemini/skills/impeccable

# Link an entire category
ln -s /home/youssef/skills/design-ui/* ~/.gemini/skills/
```

### 3. Loading into Anthropic Claude Code

Claude Code supports custom project-level and user-level skills in `.claude/skills/`:

```bash
mkdir -p .claude/skills
cp -r /home/youssef/skills/code-review-refactoring/code-reviewer .claude/skills/
```

### 4. Loading into CLI Agent Orchestrator (CAO)

Register skills with CAO via its built-in skill management toolchain:

```bash
cao skills link /home/youssef/skills/multi-agent-orchestration/cao-workflow
```

### 5. Loading into GitHub Copilot CLI & VSCode Agent

Place skills in the `.github/skills/` directory of your target repository:

```bash
mkdir -p .github/skills
cp -r /home/youssef/skills/testing-qa/playwright-cli .github/skills/
```
